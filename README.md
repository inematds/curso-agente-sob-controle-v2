# Agente sob Controle (v2) — Use agentes de IA sem se queimar

Curso gratuito do INEMA.CLUB, formato `formato-curso-v2` (dark âmbar, trilhas e módulos, camada de aprendizagem: marcar lido, dúvidas, grifos, "minha jornada", export/import, temas).

Para quem tem um pequeno negócio e começa a usar agentes de IA: escolher o problema certo, limitar o que o agente pode tocar, fechar as portas de segurança que quase ninguém vê e medir se deu certo.

**Curso:** https://inematds.github.io/curso-agente-sob-controle-v2/

## Estrutura

| Trilha | Módulos |
|---|---|
| 1 · 🚦 Por que agora | 1.1 Responder não é agir · 1.2 Mais capaz, mais limites |
| 2 · 🔎 Achar a dor | 2.1 A pergunta do 10× · 2.2 Pedido não é problema |
| 3 · 🔐 Controlar o sistema | 3.1 As cinco chaves · 3.2 Três regras e casos reais |
| 4 · 🕳️ O que quase ninguém conta | 4.1 Ordens escondidas · 4.2 Senhas e extensões · 4.3 Gasto, isolamento e LGPD |
| 5 · 📊 Assumir o resultado | 5.1 Métrica com dono · 5.2 A planilha em 4 blocos |

11 módulos × 6 tópicos = 66 tópicos. HTML estático (Tailwind via CDN + `assets/learn.css`/`learn.js`), abre direto no navegador.
